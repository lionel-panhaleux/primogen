# Primogen

A [VTES](https://www.vekn.net) (Vampire: The Eternal Struggle) councilor for
any LLM assistant: rules answers that quote what settles them, deck analysis
and advice, a meta picture with numbers.

It is an MCP server with no LLM on the server side: it returns verbatim card
texts, rulings, rules sections and computed deck and tournament facts, and
your own assistant writes the answer. It will be hosted at `mcp.krcg.org` and
runnable locally from the same binary.

**Status: design decided, nothing built yet.** [`docs/index.md`](docs/index.md)
maps what it is and what was decided; [`BOARD.md`](BOARD.md) holds the work.
Setup instructions arrive with the first served tool.
